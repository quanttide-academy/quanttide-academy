# Reference: 双向 Peer-Buddy 撮合门槛与私聊破冰草稿

本文件为 [SKILL.md](../SKILL.md) 的匹配筛选准则与文案参考，核心目标：**压缩协调缺口（Gap），绝不制造新的协调噪声（Noise）**。

---

## 一、双向撮合评分门槛（拒绝泛标签硬凑）

| 匹配方向 | 必须满足的强匹配条件 | 不推送（直接过滤） |
| :--- | :--- | :--- |
| **供给向（我能顺手帮 TA）** | 同伴挂出了 `OPEN` 困惑，且具体卡点直接命中我本地的 `Offer`、`Playbooks` 或 `Q1 核心优势区`，且**不触碰我的 `Avoid` 边界**。 | 仅凭“都在做 AI”“都在基地”等宽泛重叠。 |
| **需求向（TA 能帮我 / 可搭伙）** | ① 我当前有 `OPEN` 困惑，而同伴的 `Offer` / `Playbooks` 明确覆盖该问题；或 ② 我的 `Seek` 与同伴的 `Offer`、同伴的 `Seek` 与我的 `Offer` 形成**双向互补**，且投入时段无硬冲突。 | 单向泛泛兴趣、说不清具体哪一件事可以请教或怎么分工。 |

### 排序优先级与上限
1. **排序**：`超时 > 48h 的高匹配 OPEN 困惑` > `双向强互补 2 周微实验搭伙` > `一般供给/需求线索`。
2. **硬上限**：Layer 0 按需巡检最多 **3 条**；Layer 1 搭便车增量巡检最多 **1–2 条**；无强匹配时诚实报告 0 条。

## 二、飞书私聊破冰草稿模板（绝不自动代发，仅供复制微调）

### 供给向（我能顺手帮对方）
> 「哈喽，在基地公共索引看到你挂出的 `[B-YYYYMMDD-01]` 卡在 XX 环节——我前两天刚把类似流程跑通、踩过一个小坑，如果你方便的话我可以发你一份简短步骤或异步帮你看一眼？」

### 需求向（向对方请教 / 提议 2 周微实验搭伙）
> 「哈喽，在基地公共索引看到你最近在做 XX、擅长 YY，我这周正好在推 ZZ（或卡在 `[B-YYYYMMDD-01]`）——方便抽空异步请教一个具体问题，或者看看咱们手头的 2 周小实验有没有互补切口吗？」

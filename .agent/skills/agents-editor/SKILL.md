# AGENTS.md 编辑

## 流程

1. 阅读本文件全部内容
2. 按模板逐节顺序执行；查不到的信息保留占位，不猜测填写
3. 对照验收清单自检落盘

## 模板

```markdown

## 项目概述（必填）

通读项目全部文件进行总结，不超过三行。

## 相关文档（必填）

README、CHANGELOG 等入口链接，用相对路径。

## 快速定位（选填）

捕捉用户对话信息，触发关键词和近似关键词，快速定位项目文件及其锚点内容。  
问询用户本节有无必要生成，若生成，示例如下：  

| **关键词** | **文件** | **锚点** |
| :--- | :--- | :--- |
| xx | [xx.md](<xx.md>) | 原文文本/标题 |

## 业务意图（必填）

通读项目全部文件，总结项目业务意图，不超过三行。  

## 关键决策（必填）

通读项目全部文件，总结项目关键决策，以有序列表列出，不超过 5 条。  

## 管道逻辑（选填）

问询用户本节有无必要生成，若生成，以 mermaid 语法总结管道逻辑，简单概括项目核心模块和产出的数据流向。  

## 技术栈（选填）

问询用户本节有无必要生成，若生成，通读项目全部文件，总结主要技术栈，不超过 5 个，精确到主版本号。

## 项目目录（必填）

简单树目录，不全部展开，只列关键文件和文件夹并标注职能，示例如下：  

quanttide-academy/
├── README.md
├── AGENTS.md
├── roadmap.md
├── .gitignore
├── docs/                              # 程序型记忆
│   ├── bylaw/                         # Bylaw（工作章程）
│   ├── handbook/                      # Handbook（工作手册）
│   ├── specification/                 # Specification（工程标准）
│   └── tutorial/                      # Tutorial（工作教程）
└── .agent/                            # Toolkit（工作所需 skill 与脚本）

## 关键文件（选填）

问询用户本节有无必要生成，若生成，列出关键文件，不超过 5 条，示例如下：  

| **文件** | **职能** |
| :--- | :--- |
| [xx.md](<xx.md>) | xxx |

## 常用命令（选填）

问询用户本节有无必要生成，若生成，根据项目全部文件，列出开发、测试、质检阶段重要命令，不超过 5 条。 

## 核心原则（必填）

只放影响 AI 行为的指令，缺了会做错、或必须遵守的刚性规则，固定生成的示例如下，可根据项目需求扩展，但不超过 10 条： 

- 最小干预：仅在用户明确请求时改文件，不主动超出更改范围改无关文件
- 用到再建：除本树已有路径和 README、AGENTS.md 这类根契约外，不创建未使用的（代码）文件或目录
- 结构同步：改名或变更目录后，README、和本文对应内容与内部链接必须同一轮改完
- 最大兼容：优先 GFM / CommonMark / Latex，不用编辑器私有语法
- 信息复用：不把项目中某文件正文抄进其他文件，采用相对链接

## 常见任务（选填）

项目有高频重复操作才写入
问询用户本节有无必要生成，若生成，依据用户描述，列出常见任务，示例如下：

### xxx

1. 每步一行，简短精炼
2. 

## 工作流程（必填）

有序列表，每步一句话，简短精炼。

## 安全约束（必填）

固定生成的示例如下，可根据项目需求扩展，但不超过 5 条： 

- 禁止把密钥、口令、令牌写进仓库文件或协作材料（设计、截图、视频、任务页）
- 

## 验证清单（必填）

复选框，覆盖关键产出物，全部通过才算完成。

- [ ] 

```

# README 撰写与刷新

先读本文件再动手。

内容与结构按本文件；Markdown 排版格式（frontmatter、标题、加粗、引号、链接写法、空行）遵循 `.agent/skills/markdown-editor/SKILL.md`，落盘前读一次并按其核对。本 skill 不重复规定格式。

## 流程

1. 通读仓库现状：目录结构、既有规范文件（章程、任务清单等，按仓库实际），确认仓库职能与入口
2. 已有 README：读全文，逐节比对哪些已过期、哪些缺。无 README：按模板生成全文，必填节直接写
3. 按模板刷新；`（选填）` 的节先问用户有无必要
4. 对照验收清单自检落盘

## 模板

示例以实训基地仓库为参照，其他仓库按实际目录替换。

```markdown
# 仓库名

（必填）一句话说清本仓库存什么、承接什么协作。示例如下：

本仓库存放量潮实训基地的文档（规章、任务清单、工程规范）及可复用工具，承接实训基地的多人异步协作工作。

## quick-start（必填）

给新成员的最短上手路径，有序列表，每步一个链接。示例如下：

1. [了解量潮科技](https://strategy.quanttide.com/)
2. [了解实训基地](./docs/bylaw/index.md)
3. [如何领取任务](./roadmap.md)

## 仓库结构（必填）

简单树，只列关键文件与文件夹并标注职能。`.agent/` 只列一行，不展开内部。示例如下：

quanttide-academy/
├── README.md                        # 人类阅读入口
├── AGENTS.md                        # AI 工作指南
├── roadmap.md                       # 任务清单
├── docs/                            # 程序型记忆
│   ├── bylaw/                       # 工作章程
│   └── handbook/                    # 协作流程
└── .agent/                          # skill

## 待办与路线（选填）

仓库有公开任务清单才写，链过去，不在 README 复述条目。
```

## 刷新规则

- 只改过期的节，其余原样保留，不整篇重写
- 模板外的已有节默认保留；混入的 AI 行为约束类内容或疑似冗余，向用户指出，不自行挪动删改
- 结构树与实际目录一致，`.agent/` 不展开
- 相对链接指向仓库内已存在的文件，外部链接保留原样
- 发现过期但不属本次范围的内容，先问用户，不顺手改

## 验收清单

- [ ] 现有 README 已通读，改动范围与本次变更对得上；无 README 时按模板生成
- [ ] 简介、quick-start、仓库结构三节齐全，选填节已问询用户
- [ ] 落盘稿中无模板说明行与示例残留
- [ ] 仓库结构与实际目录一致，`.agent/` 未展开
- [ ] 内部链接指向已存在的文件
- [ ] 未把其他文件正文抄进 README
- [ ] 未重复规定 Markdown 排版格式
- [ ] 全文小于 150 行

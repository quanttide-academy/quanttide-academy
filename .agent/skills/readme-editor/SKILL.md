# README.md 编辑

## 流程

1. 通读仓库现状，确认仓库职能与入口；已有 README 读全文，逐节比对哪些过期、哪些缺失
2. 按模板只改过期的节，其余原样保留，不整篇重写；无 README 时按模板生成全文
3. 标（选填）的节先问询用户
4. 模板外的已有节默认保留；混入的 AI 行为约束类内容或疑似冗余，向用户指出，不自行挪动删改
5. Markdown 排版格式（frontmatter、标题、加粗、引号、空行）遵循 `markdown-editor` skill，本 skill 不重复规定
6. 对照验收清单自检落盘

## 模板

```markdown

# 仓库名

（必填）简介，一句话说清本仓库存什么、承接什么协作。

## quick-start（必填）

给新成员的最短上手路径，有序列表，每步一个链接。

## 仓库结构（必填）

简单树，不全部展开，只列关键文件与文件夹并标注职能。`.agent/` 只列一行，不展开内部。

## 待办与路线（选填）

仓库有公开任务清单才写，链过去，不复述条目。

```

## 验收清单

- [ ] 现有 README 已通读，改动范围与本次变更对得上；无 README 时按模板生成
- [ ] 简介、quick-start、仓库结构齐全，选填节已问询用户
- [ ] 落盘稿中无模板说明行与示例残留
- [ ] 仓库结构与实际目录一致，`.agent/` 未展开
- [ ] 内部链接指向已存在的文件
- [ ] 未把其他文件正文抄进 README
- [ ] 未重复规定 Markdown 排版格式
- [ ] 全文小于 150 行

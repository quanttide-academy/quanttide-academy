# 实训基地章程

## 战略定位

实训基地是由受训实习生组成的量潮影子公司，依托量潮的资源、工具与业务场景，以最低运营成本自组织、自进化。  

## 价值体系

- 开源，贡献与收获集体智慧；
- 合作互助大于竞争内卷；
- 个人通过实训锻炼真实能力，加速成长，打磨简历；
- 基地利用个人与集体的进步和产出实现进化；
- 公司筛选并吸纳优秀人才；

## 目标

### 短期

- 人才池：向量潮输送符合自由体系标准的人才，以降低入职摩擦，在业务紧张时提供弹性人力储备；
- 学习社区：建立工程方法和规范的学习社区，以真实需求和项目为纽带，促进学员间的交流与合作；

### 远景

- 产品交付：承接量潮众包与公司相关需求任务，将内部协作摩擦沉淀为产品；
- 多租户沙盒：作为第二组织，验证量潮云企业服务的多租户（Multi-tenant）架构与跨租户协同；

## 工作生态

- 实训基地小群（管委会）：唠嗑吹水、交流学习、简单交接；
- 实训基地大群：唠嗑吹水、交流学习、组队交友；
- GitHub 仓库：协作平台，知识资产存储与托管；

## 工作约定

- 工作时间：9:30 到 22:30 飞书弹消息，其他时间不建议，给彼此生活空间；
- 异步沟通：通过  GitHub + DDL 约束；

## 架构职能

- 主席/副主席：推动议程落地，引导组织进化；
- 专职秘书：协助主席，维护流程规范，安排日常事宜；
- 技术骨干：负责技术方案设计与实现；

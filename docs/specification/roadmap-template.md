# 任务清单模板

本模板定义 [任务清单](../../roadmap.md) 中每一个条目的写法。  

## 积分对照

| **难度** | **积分** |
| :-- | --: |
| 简单 | 10～15 |
| 中等 | 25～35 |
| 难 | 50～60 |
| 特难 | 70～90 |

本表积分与任务 Issue 必须一致。积分必须是该难度闭区间内的整数；16～24、36～49、61～69 为空档，不合法。  

## 模板

新增条目时整段复制以下代码块，用已知信息替换尖括号占位。  

```markdown
## <仓库名，尚无仓库时用中文需求短名，全条目唯一>

### 基本信息

- 发起人：<人名>
- 发起日期：<yy-mm-dd>
- 项目描述：<一句话说清做什么、给谁用>
- 验收标准：[链接](<URL>)
- 仓库入口：<URL 或 待建>
- 计分板：<URL 或 待建>

### 人员信息

| **人名** | **GitHub ID** | **邮箱** | **角色** |
| :-- | :-- | :-- | :-- |
| <人名> | <@ID> | <邮箱> | <管理员，唯一，默认为项目发起人> |
| <人名> | <@ID> | <邮箱> | <审核员> |

### 任务概览

| **难度** | **积分** | **任务** | **状态** |
| :-- | --: | :-- | :-- |
| <简单 | 中等 | 难 | 特难> | <该行难度区间内的一个整数> | [<#N 短标题>](<Issue URL>) | <提议中 | 可领取 | 进行中 | 已结项> |
```

## 校验

- [ ] 不写密钥、令牌等凭据
- [ ] 二级标题全清单唯一；无仓库时用中文需求短名
- [ ] 基本信息六项已填；发起日期为 yy-mm-dd；项目描述一句话说清做什么、给谁用
- [ ] 验收标准为可打开链接；仓库入口、计分板为 URL 或「待建」
- [ ] 人员表四列对应；角色只能是管理员或审核员；管理员唯一，默认为发起人
- [ ] 任务表四列对应；难度与状态取值与模板一致；任务为 `[#N 短标题](Issue URL)`，编号与仓库一致
- [ ] 积分为该行难度闭区间内整数且非空档，与积分对照表及 Issue 一致
- [ ] 表格结构严格遵守模板；条目按发起日期排序

# Brief template

本文规定周会信息简报的文件名和正文版式。  
版式与 [261021](../../data/report/weekly-brief/261021.md) 一致。  
写新简报前先读本文，再照正文版式填写。  

## 文件命名

周会简报放在 `data/report/weekly-brief/`。文件名取正文时间的日期，年份用后两位，月和日各两位，中间不空。2026-10-21 的文件名是 `261021.md`。  

## 正文版式

抬头五行每行末尾留两个空格。  

```markdown
# …… 月第……周对齐会议 · 信息简报

**时间**：……-……-…… ……:……–……:……  
**主持**：……  
**记录**：……  
**参会**：……、……  
**出勤**：……  

---

## 决议

1. ……只接收……的汇报，只把控方向与重大事项审核，非必要不越级上报；日常事务由……处理；问题先自行判断，解决不了再逐级上报。
2. ……由……直接负责

## 待办

### ……

1. ……
2. ……[文字](链接)……
3. 优先级：紧急重要、缓和重要、紧急次要、缓和次要
4. 负责人：……
5. 审核人：负责人互审，鲍宇航终审
6. DDL：YY-MM-DD
```
